# Walkthrough by channel

### 1. Intercept (radio)

1. Tune to **097.9** (gold when exact). Hold until lock.
2. Celeste speaks; asks for `#signals`. Gate opens to pad.

EXTRA: **033.3** blood poem early (no hard lock). Eggs **010.5 / 051.2 / 066.6**. After lock once: pad ↔ tuner handoff.

### 2. Number pad (+ Whisper)

1. Fail pad **3×** or open Kharon-Celeste.
2. Ask for help (affirmative / **please**).
3. Return to tuner → **033.3** → Whisper key **blood**.
4. Sudoku → pad **512** → hub (music starts).

EXTRA: Whisper **reward** then **no**. Eggs: `who are you` → TURN AROUND; **Kian**; early **512**. Author pad eggs: **111 / 222 / 420 / 666**.

### 3. Terminal (FTHFLL)

1. `/outer` → **G512** → **S. Raei** *or* skip to `/inner`.
2. `/inner` → **EL0 WL3 NR5** (also arms optics if needed).

EXTRA: `/landing` · `/protocol` · `/echo` · `/moon` · `/edge` · `/translate` · `/passage` · gated `/volume` · `Celeste` → Turn around. Full answers in glossary.

### 4. STATUS → INNER bays

1. INNER goes live after `/inner`.
2. **STELLAR FIX** → Chart · **PERSONAL RECORD** → Flight Log.

### 5. System Chart

1. Sturm free; The Nine sealed until each world’s Chart purge (glossary table).
2. Dossiers teach **bind order** only (named seals) — not volume codes.
3. Soft loop: Qamor / Ikeph / Terra / Uros first; outer worlds use the shipped verbs above.

### 6. Flight Log

1. Flat list after PERSONAL RECORD bay — no per-planet airlocks or volume keys.
2. Search filters the list; open entries; click fragment words into the tray.
3. Soft loop: claim **STURM** → **HIVE** → **OATH** → **CARA** (then outer worlds).

### 7. Imperial Clearance

1. Nine wells inward→outward: planet + fragment.
2. Correct bind → animation (music out → banquet in → music back).
3. Unlocks Archives + Guest; decrypts all Log.
