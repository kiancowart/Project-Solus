# Flight Log entry recordings

Drop per-entry voice beds here and point `audio` on that entry in
`content/flight-log-entries.js`.

Convention:
- `assets/audio/voice/flight-log/<entry-id>.mp3` (or a clear slug)
- Prefer mono/stereo MP3 ≈96–128 kbps
- Wire with: `audio: "assets/audio/voice/flight-log/<file>.mp3"`
